# Lâmpada

App pessoal de plano de leitura bíblica, instalável no celular e que funciona sem internet.

Esta é a versão de demonstração: o texto bíblico é de exemplo e os dados ficam só no aparelho.

## Regra deste repositório

O repositório é público. **O texto da Bíblia (NAA) e qualquer arquivo convertido a partir dele nunca devem ser enviados para cá.** O texto fica só no celular e no Google Drive.

## Arquivos

| Arquivo | Para que serve |
| --- | --- |
| `index.html` | O app inteiro |
| `fontes.css` | Fontes do app, para funcionar sem internet |
| `manifest.webmanifest` | Nome, cores e ícones usados na instalação |
| `sw.js` | Guarda o app no celular para abrir sem internet |
| `icone-192.png`, `icone-512.png`, `apple-touch-icon.png` | Ícones |

## Atualizar o app

1. Enviar os arquivos novos por **Add file → Upload files** e clicar em **Commit changes**.
2. Esperar um ou dois minutos para o GitHub Pages publicar.
3. No celular, abrir o app com internet, fechar e abrir de novo.
